## 🌟 平台介绍
五极云是杭州五极网络技术有限公司自主研发**企业级零代码开发平台**，采用前后端分离架构，无需大量编写代码，通过可视化拖拽方式，快速搭建各类企业业务管理系统。

平台内置成熟业务体系，覆盖**仓库WMS管理、客户CRM管理、进销存管理、OA办公、流程审批、数据报表统计**等主流场景，集成入库、出库、库存调拨、智能盘点、数据可视化大屏、角色权限管理等实用功能，开箱即用，极大降低中小企业数字化转型成本。

开源版开放核心底层源码，适合开发者学习低代码架构设计、流程编排逻辑、数据权限设计、前端可视化搭建思路。

## 🛠 技术栈
- **后端技术**：Java 8+、Spring Boot、Spring Security、MyBatis-Plus、Redis、MySQL 8.0
- **前端技术**：React、Ant Design、Umi、TypeScript、可视化拖拽引擎
- **核心架构**：数据建模引擎、表单设计引擎、业务流程引擎、多级权限体系、数据可视化组件

## 🎯 核心功能
1. **可视化拖拽设计**：零代码拖拽布局，快速制作表单、页面、业务模块
2. **自定义数据模型**：可视化建表，自动生成增删改查基础功能
3. **完整仓储管理**：货品入库、订单出库、跨仓调拨、库存盘点、库存预警
4. **智能数据统计**：自动汇总业务数据，生成统计报表与可视化数据看板
5. **客户管理系统**：客户档案、跟进记录、合同管理、销售数据统计
6. **流程审批引擎**：自定义审批流程、条件流转、消息通知
7. **精细化权限控制**：组织架构、角色权限、用户权限、数据权限多层隔离
8. **系统集成能力**：支持API对接、第三方数据互通、内外系统联动
9. **多端适配**：PC端完整管理，移动端同步查看操作

## 🚀 全平台一键快速部署
### Windows 一键安装
```shell
# 下载部署脚本
wget https://install.elemost.com/wujiyun/windows_install.bat
# 鼠标右键以管理员身份运行脚本
# 自动配置运行环境、初始化数据库、一键启动全部服务

### Linux 一键安装（CentOS / Ubuntu）
# 服务器终端执行一键部署命令
curl -fsSL https://install.elemost.com/wujiyun/linux_install.sh | bash

# 启动服务
systemctl start wujiyun

# 访问地址
http://服务器IP地址:8080

### MacOS 一键安装
# 终端执行安装命令
bash <(curl -s https://install.elemost.com/wujiyun/mac_install.sh)

# 启动项目
./start.sh
