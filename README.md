### 平台简介
**五极云**是由杭州五极网络技术有限公司打造的 **AI+aPaaS 企业级零代码应用搭建平台**，致力于让企业“**少写代码、快速上线、自主可控**”，低成本实现数字化转型。

平台面向中小企业与技术团队，提供**可视化拖拽、数据模型驱动、流程自动化、权限精细化、数据大屏集成**等核心能力，可快速搭建 **CRM、WMS、进销存、OA、工单、项目管理、人事行政**等系统，开箱即用、灵活扩展。

开源版定位：**技术学习 + 内部自用**，帮助开发者掌握零代码平台底层架构、数据引擎、权限体系与前端可视化设计思路。

---

### ✨ 核心能力
- 🧩 **可视化应用设计器**：拖拽组件、自由布局、实时预览，无需前端代码
- 📊 **数据模型管理**：零SQL建表、字段类型丰富、主从关联、自动生成CRUD
- 🔄 **流程自动化引擎**：审批流、条件分支、并行处理、自动消息、任务委派
- 🔐 **企业级权限体系**：组织/角色/用户三级权限，字段级控制、数据隔离
- 📈 **数据大屏与看板**：图表、地图、统计组件，实时数据可视化
- 🧠 **AI辅助开发**：智能建表、流程推荐、公式助手（开源版部分开放）
- 🔗 **系统集成能力**：API连接器、WebHook、数据同步、打破信息孤岛

### 🚀 快速部署（本地/内网）
#### 环境要求
- JDK 1.8+
- MySQL 5.7 / 8.0
- Redis 5.0+
- Node.js 16+（前端编译）

#### 部署步骤
1. `git clone https://github.com/你的账号/你的仓库名.git`
2. 后端：Maven 打包 → 配置数据库/Redis → 启动
3. 前端：`npm install && npm run build` → 部署到 Nginx
4. 访问：默认端口 8080，管理员账号密码见配置文件

> 详细部署文档见 `/docs` 目录。
